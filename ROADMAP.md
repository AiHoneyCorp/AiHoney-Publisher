# Roadmap

AiHoney Publisher is in active private development. This roadmap is intentionally high level and may change as platform requirements evolve.

## Current priorities

- stabilize multi-platform publishing for existing integrations
- expand official OAuth/API integrations where available
- continue improving Auto-Calendar scheduling and retry behavior
- improve platform-specific metadata and destination selection
- reduce setup and publishing friction for non-technical users
- improve performance for large media batches

## Platform roadmap

### Working / active development

- DeviantArt
- X
- RedGIFs
- Fanvue

### In development

- Reddit OAuth/Data API integration

### Planned

- additional creator platforms selected according to API availability, creator demand, and unattended scheduling reliability

## Product direction

AiHoney Publisher is ultimately intended for a mass-market creator audience. The product goal is that users should be able to connect accounts, review media, apply platform-specific metadata, schedule content, and publish across platforms without understanding developer APIs, browser automation, redirect URIs, or platform-specific technical implementation details.

## Documentation roadmap

This public repository will continue to publish:

- product descriptions
- privacy and security information
- data-use explanations
- platform integration summaries
- API-review documentation where required

The proprietary production source code will remain private unless AiHoney explicitly announces otherwise.
